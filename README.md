Assignment Submission Portal

Online Assignment Management System for Students and Faculty

Project Overview

Assignment Submission Portal is a web-based application designed to help students submit assignments online and enable faculty members to manage and review submissions efficiently. The system provides user authentication, assignment management, file upload, and submission tracking features to support academic activities.

The project is being developed using Python Flask as the backend framework and MySQL as the database management system.
